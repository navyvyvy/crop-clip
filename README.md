# CropClip

[![Chrome Web Store에서 설치](https://developer.chrome.com/static/docs/webstore/branding/image/tbyBjqi7Zu733AAKA5n4.png)](https://chromewebstore.google.com/detail/idjkjkfehhhaeacngchpolnajodfibil)

치지직 방송의 전체 화면이나 원하는 영역을 녹화하고, 필요한 구간을 잘라 저장하는 Chrome 확장 프로그램입니다.

녹화와 편집은 브라우저 안에서 처리하며 영상을 외부 서버로 전송하지 않습니다.

## 주요 기능

- 전체 화면·선택 영역 녹화, 최대 4개 영역 합성
- 미리보기와 0.1초 단위 구간 선택
- 절반·3분할·4분할, 시간·용량 기준 파일 나누기
- MP4·GIF 변환과 0.5~4배속 MP4 저장
- PNG 스크린샷과 영상 장면 저장
- 원본·분할 파일 자동 다운로드와 단축키 설정

## 사용 방법

1. 치지직 플레이어에서 `녹화 영역 선택`을 누르고 영역을 지정합니다.
2. 선택 영역의 녹화 버튼이나 확장 프로그램 창에서 녹화를 시작합니다.
3. 녹화를 정지한 뒤 결과창에서 구간을 조절하고 다운로드합니다.

전체 녹화·단축키·자동 다운로드는 확장 프로그램 설정에서 켤 수 있습니다. 음소거한 채 녹화하려면 `음소거 중 녹화 허용`을 켜세요.

실험 옵션인 `전체 녹화 원본 사용`을 켜면 지원되는 방송에서 재생 중인 화질과 프레임률 그대로 최대 5분을 MP4에 저장합니다. 비트레이트 설정은 원본 저장에 적용되지 않습니다. 용량 한도는 영상과 음성을 합쳐 8.5Mbps로 5분, 약 319MB를 기준으로 시작·끝 조각의 여유를 둡니다. 이보다 높은 비트레이트에서는 5분 전에 저장될 수 있습니다. 원본을 사용할 수 없으면 설정한 저장 형식(WebM 또는 MP4)과 비트레이트로 화면을 녹화합니다. 원본 사용을 켠 녹화의 결과창에는 방송 원본 또는 화면 녹화를 표시합니다.

`녹화 용량 표시`를 켜면 팝업과 녹화 버튼 옆 타이머에 현재까지 기록한 용량을 표시합니다.

결과창을 닫으면 임시 영상은 약 10분 뒤 삭제됩니다.

## 패치노트

<details open>
<summary><strong>v0.4.0</strong></summary>

새 기능

- 방송 원본 저장을 추가했습니다. ‘전체 녹화 원본 사용’을 켜면 지원되는 치지직 방송을 시청 중인 화질 그대로 최대 5분까지 MP4로 저장합니다. 원본을 불러오지 못하면 화면 녹화로 저장합니다.
- 팝업과 플레이어에 녹화 용량과 시간을 함께 표시하는 옵션을 추가했습니다.

개선 사항

- 전체 녹화 파일의 초반 끊김 보정과 저장 복구 개선
- 메모리 사용량 개선
- 녹화·저장·변환 내부 구조 개선

</details>

<details>
<summary><strong>v0.3.13</strong></summary>

녹화 안정화

- 방송 재생 중 H.264 지원 여부를 미리 확인해 녹화 시작 시 중복 확인을 줄였습니다.
- 전체 H.264 녹화 초반에 끊김이 감지되면 WebM·MP4 저장 파일에서 해당 구간을 재인코딩 없이 제외합니다.
- 녹화 중 다른 탭의 녹화·영역 선택을 잠그고, 잠긴 버튼에 이유를 표시합니다.
- 전체 녹화 중 선택 영역을 지울 수 있으며, 연달아 삭제해도 지운 영역이 되살아나지 않습니다.
- 녹화 준비 중에도 정지·취소를 예약할 수 있고, 녹화가 끝나면 변경한 영역 개수 제한을 적용합니다.
- 녹화·변환이 끝난 뒤 자원 해제를 개선하고, 결과창을 닫은 뒤 임시 영상 삭제가 실패하면 다시 시도합니다.

</details>

<details>
<summary><strong>v0.3.12</strong></summary>

녹화 성능 개선

- 영상 처리 API(VideoFrame·MediaStreamTrackGenerator)를 새로 적용해 전체·단일 영역 녹화 시작 시 방송 끊김과 처리 부하를 줄였습니다. 화질 설정과 빠른 MP4 변환은 유지합니다.
- MP4 영역 녹화 충돌과 MP4 분할 파일의 초반 멈춤·개수 오류를 수정했습니다.
- 녹화 종료 응답과 자원 해제를 개선하고, 상태 조회·용량 분할 재시도의 중복 처리를 줄였습니다.
- 이전 녹화의 지연된 종료 요청이 새 녹화를 끊는 문제를 수정했습니다.
- 파일 저장 중에는 녹화 시간 대신 저장 중 상태를 표시합니다.
- 분할 파일은 마지막 번호부터 하나씩 저장해 다운로드 폴더의 수정한 날짜 최신순에서 1번이 위에 오도록 했습니다.

</details>
