# CropClip

[![Chrome Web Store에서 설치](https://developer.chrome.com/static/docs/webstore/branding/image/tbyBjqi7Zu733AAKA5n4.png)](https://chromewebstore.google.com/detail/idjkjkfehhhaeacngchpolnajodfibil)

치지직 방송의 전체 화면이나 원하는 영역을 녹화하고, 필요한 구간을 잘라 저장하는 Chrome 확장 프로그램입니다.

녹화와 편집은 브라우저 안에서 처리하며 영상을 외부 서버로 전송하지 않습니다.

## 주요 기능

- 전체 화면·선택 영역 녹화, 최대 4개 영역 합성
- 미리보기와 0.1초 단위 구간 선택
- 절반·3분할·4분할, 시간·용량 기준 파일 나누기
- MP4·GIF 변환과 0.5~4배속 MP4 저장
- PNG 스크린샷과 영상 장면 저장
- 원본·분할 파일 자동 다운로드와 단축키 설정

## 사용 방법

1. 치지직 플레이어에서 `녹화 영역 선택`을 누르고 영역을 지정합니다.
2. 선택 영역의 녹화 버튼이나 확장 프로그램 창에서 녹화를 시작합니다.
3. 녹화를 정지한 뒤 결과창에서 구간을 조절하고 다운로드합니다.

전체 녹화·단축키·자동 다운로드는 확장 프로그램 설정에서 켤 수 있습니다. 음소거한 채 녹화하려면 `음소거 중 녹화 허용`을 켜세요.

실험 옵션인 `전체 녹화 원본 사용`을 켜면 지원되는 방송에서 재생 중인 화질과 프레임률 그대로 최대 5분을 MP4에 저장합니다. 5분은 방송 재생 시간 기준이며, 원본의 비트레이트를 유지합니다. 원본을 사용할 수 없으면 설정한 저장 형식(WebM 또는 MP4)과 비트레이트로 화면을 녹화합니다. 원본 사용을 켠 녹화의 결과창에는 방송 원본 또는 화면 녹화를 표시합니다.

`녹화 용량 표시`를 켜면 팝업과 녹화 버튼 옆 타이머에 현재까지 기록한 용량을 표시합니다.

결과창을 닫으면 임시 영상은 약 10분 뒤 삭제됩니다.

<details>
<summary>기본 단축키</summary>

| 키 | 기능 |
| --- | --- |
| `a` | 영역 선택 |
| `x` | 활성 영역 해제 |
| `z` | 전체 영역 해제 |
| `r` | 영역 녹화 시작·정지 |
| `c` | 녹화 취소 |
| `s` | 영역 스크린샷 |
| `e` | 전체 녹화 시작·정지 |
| `d` | 전체 스크린샷 |

위 녹화 단축키는 설정에서 켤 수 있습니다. 입력란에 글자를 쓰는 동안에는 단축키가 실행되지 않습니다.

결과창 플레이어에서는 `m`을 눌러 음소거를 켜고 끌 수 있습니다. 대문자 `M`과 한글 두벌식 `ㅡ`도 사용할 수 있습니다.

</details>

- 방송 원본 저장 호환성 개선
- 결과창 음소거 단축키 추가 (M·ㅡ)

<details>
<summary><strong>v0.4.1</strong></summary>

- 설정을 녹화·저장 및 분할·단축키 탭으로 정리했습니다.
- 녹화 후 자동 분할과 자동 다운로드를 설정하고, 다운로드가 끝난 뒤 결과창을 유지할 수 있습니다.
- 화면 녹화 기본 비트레이트를 8Mbps, 상한을 16Mbps로 높이고, 지원 환경에서 MP4 H.265 녹화를 추가했습니다.
- WebM·MP4 녹화의 초반과 중간에 프레임이 불규칙하게 빠지는 문제를 줄이고, 방송 원본 저장을 재생 시간 기준 최대 5분으로 맞췄습니다.
- 방송 원본을 찾지 못했을 때 화면 녹화 저장 작업이 몰리는 현상을 줄였습니다.
- 결과창의 미리보기와 다운로드 동작을 개선하고, 파일을 나누기 전에 조각별 예상 용량을 표시합니다.

</details>
