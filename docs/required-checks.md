# 필수 기능 확인 목록

릴리스에 사용할 빌드에서 `npm run check`를 실행한다. 이 명령은 확장 프로그램을 빌드하고 단위 검사와 브라우저 검사를 실행한다. Windows에서 Edge로 확인할 때는 실행 전에 `$env:CROPCLIP_TEST_BROWSER = 'msedge'`를 설정한다. GitHub 빌드는 Chromium에서 같은 필수 브라우저 검사 목록을 사용한다.

| 필수 기능 | 통과 기준 | 자동 검사 |
| --- | --- | --- |
| 녹화 시작·정지·취소 | 전체·영역 녹화가 버튼과 단축키로 동작한다. 시작 응답이 늦어도 정지·취소가 처리되고, 저장 응답이 늦어도 인코더가 바로 멈춘다. 음소거 중에는 허용 설정을 켰을 때 녹화할 수 있다. | [녹화 조작과 저장](../tests/browser/extension.spec.mjs), [반복 취소](../tests/browser/recording-cancel.spec.mjs), [음소거 설정](../scripts/check-recording-cleanup.mjs) |
| 비트레이트·녹화 코덱 | 전체·단일 영역·다중 영역 녹화와 방송 원본 조회 실패 후의 화면 녹화에 현재 목표 비트레이트가 적용된다. H.265 옵션은 MP4에서 선택할 수 있으며, 재생 중인 H.265 트랙과 인코더 지원이 확인된 경우 H.265로 녹화한다. 1080p 소스에 16Mbps 설정을 적용한 파일은 해상도를 유지하고 빠른 분할 후에도 재생된다. | [녹화 설정 적용](../tests/browser/extension.spec.mjs), [코덱과 분할](../tests/browser/recording-startup.spec.mjs) |
| 타이머·파일명·재생 길이 | 실제 시작 전에는 ‘시작 중’을 표시한다. 팝업·플레이어와 파일명의 시작 시각이 일치하고 원본 조회 실패 후에도 시간이 이어진다. 33초 테스트 영상은 재생 길이가 목표에서 1초 이내이고, 파일명의 길이 표기는 재생 길이를 반올림한 값과 일치한다. | [시작·원본 전환](../tests/browser/extension.spec.mjs), [33초 녹화](../tests/browser/recording-deletion.spec.mjs) |
| 영역·여러 탭·이동 | 녹화 중 다른 탭이 시작하거나 영역을 변경할 수 없다. 종료하면 잠금이 풀린다. 영역 테두리가 영상 이동을 따라가고 미니 플레이어 전환 중에 녹화가 이어진다. 같은 주소에서 이동한 플레이어나 복제된 버튼도 리방 후 작동한다. 클립 편집기에 진입하면 영역 테두리가 다시 나타나지 않는다. | [탭 잠금과 영역 저장](../tests/browser/recording-tabs.spec.mjs), [미니 플레이어와 영역 테두리](../tests/browser/extension.spec.mjs), [방송 재시작](../tests/browser/player-tools.spec.mjs) |
| 저장·복구·다운로드 | 정지 이벤트나 저장 응답이 빠져도 이미 저장된 영상이 복구되고 결과창이 중복으로 열리지 않는다. 결과 준비 중 예약한 다운로드는 준비 완료 후 같은 파일을 내보낸다. 자동 다운로드는 설정에 따라 결과창을 닫거나 유지한다. 유지한 결과창을 새로고침해도 같은 파일을 다시 받지 않으며, 실패 후 결과창에서 재시도할 수 있다. | [저장 복구와 다운로드](../tests/browser/extension.spec.mjs), [저장 복구 단위 검사](../scripts/check-recording-recovery.mjs) |
| 녹화 파일 재생·방송 원본 | 화면 표시 간격이 30ms와 40ms로 바뀌어도 녹화 초반의 30개 프레임이 모두 잡힌다. 시작 직후 360ms 멈춤을 재현했을 때 WebM·MP4 보정본과 짧은 원본이 재생된다. 녹화 타이머가 늦어져도 다운로드한 파일의 재생 속도와 영상·음성 길이가 맞고, 중간에 긴 프레임 공백이 생기지 않는다. 원본 MP4는 영상 데이터와 시작 위치를 유지하면서 저장 길이를 맞춘다. | [녹화 파일 재생](../tests/browser/recording-startup.spec.mjs), [원본 조각](../scripts/check-original-stream.mjs), [MP4 길이](../tests/browser/split-start.spec.mjs) |
| 분할·편집 | 2·3·4분할과 구간 지정이 동작하고 각 조각이 처음부터 재생된다. 시간 자동 분할은 기준 시간을 넘으면 실행하고, 용량 자동 분할은 파일이 설정 용량을 넘으면 실행한다. 선택한 방식과 MP4·WebM 형식이 결과창에 이어진다. 녹화 완료 자동 다운로드도 켜면 분할 파일을 받는다. 용량 한도 안에 있는 파일은 그대로 저장하고, 용량 분할 결과는 지정한 한도 이하다. 파일 순서, MP4 변환·배속·GIF·프레임 저장을 확인한다. | [분할·내보내기](../tests/browser/extension.spec.mjs), [분할 파일 재생과 다운로드](../tests/browser/split-start.spec.mjs) |
| 자원·임시 파일 정리 | 반복 취소 후 캡처 자원이 해제된다. 결과창 닫기와 브라우저 재시작 뒤에도 삭제 유예·재시도가 동작한다. 대용량 편집은 디스크 실패 시 원본을 보존하고, 결과창이 닫히면 임시 출력과 변환 작업을 정리한다. | [반복 취소](../tests/browser/recording-cancel.spec.mjs), [삭제와 재시작](../tests/browser/recording-deletion.spec.mjs), [대용량 편집](../tests/browser/split-start.spec.mjs) |
| 설정·플레이어 도구 | 브라우저 확장 아이콘으로 열리는 팝업에서 설정 영역이 표시된다. 왼쪽 탭과 팝업 높이가 고정되고, 내용이 길면 오른쪽 설정만 스크롤된다. 설정값은 다시 열어도 유지되고 여러 팝업에서 서로 다른 항목을 바꿔도 모두 저장된다. 단축키는 버튼 표시 설정과 별개로 동작하며 녹화 중에는 용량 표시 설정만 바꿀 수 있다. 스크린샷과 시간 탐색 안내가 동작하고 편집 화면 진입 시 스크린샷 자원이 해제된다. | [팝업과 단축키](../tests/browser/extension.spec.mjs), [스크린샷과 탐색](../tests/browser/player-tools.spec.mjs) |

[필수 브라우저 검사 목록](../scripts/required-browser-checks.mjs)의 각 테스트가 실제로 통과해야 한다. 누락, 건너뛰기, 예상 실패로 표시하거나 재시도 끝에 통과한 경우도 필수 검사 실패로 처리한다. 테스트 이름을 바꾸면 필수 검사 목록도 함께 수정한다.

자동 검사에는 테스트 영상과 저장·응답 지연 재현을 사용한다. 실제 치지직 방송과 장시간 메모리 수치의 점검 방법은 [검증 및 인계](recording-handoff.md)에 정리돼 있다.
